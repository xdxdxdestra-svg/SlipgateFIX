# Slipgate для macOS

Экспериментальная сборка Slipgate под macOS. Повторяет функционал
Windows-версии (локальный Telegram WS-прокси + обход DPI Zapret), но с
учётом особенностей macOS: своя установка Zapret в систему
(`/Library/LaunchDaemons`), свой прокси-клиент, кастомные «светофоры»
вместо нативного заголовка окна.

> ⚠️ **Статус: альфа.** Сборка не подписана Apple и не проходит
> нотаризацию, поэтому macOS блокирует запуск до ручного снятия карантина
> (см. ниже). Работает только на **Apple Silicon** (M1/M2/M3/M4, arm64) —
> сборки под Intel (x64) пока нет.

---

## Скачать

Свежая сборка собирается в GitHub Actions по каждому пушу в ветку
`macos-port`. Готовый `.app`/`.dmg` лежит в артефакте прогона:

- **Прогон сборки:** https://github.com/xdxdxdestra-svg/SlipgateFIX/actions/runs/33537104369
- **Артефакт:** `slipgate-macos-arm64` (внутри — установочный `.dmg`/`.app`,
  ~285 МБ). Дополнительно отдельным артефактом `tgws-cli-macos-arm64`
  поставляется CLI-пересборка TgWsProxy.
- Артефакты хранятся **90 дней**, затем удаляются — скачивайте сразу после
  прогона.

> Автоматических релизов/тегов под macOS нет (у CI-токена нет прав на публикацию
> тегов), поэтому единственный источник бинарника — страница прогона Actions.

## Установка

1. Откройте страницу прогона выше, нажмите **slipgate-macos-arm64** →
   **Download artifact**, распакуйте zip.
2. Перетащите `Slipgate.app` в папку `/Applications` (или запустите напрямую).
3. Снимите карантин Gatekeeper (иначе macOS откажется открывать приложение
   «от неизвестного разработчика»). В Терминале:

   ```bash
   xattr -cr /Applications/Slipgate.app
   ```

4. Запустите через **правый клик → Открыть** (или «Open Anyway» в
   Системные настройки → Конфиденциальность и безопасность). Обычный
   двойной клик при первом запуске может выдать «приложение повреждено» —
   это ожидаемо, лечится пунктом 3 + правый клик.
5. При первом старте Zapret macOS спросит **пароль администратора** —
   он нужен, чтобы установить LaunchDaemon (`/Library/LaunchDaemons`) и
   сетевой фильтр. Без этого Zapret не поднимется.

## Быстрый старт

- **Zapret.** На свежеустановленной macOS Zapret ещё не стоит в системе —
  на странице «Zapret» появится кнопка **«Установить Zapret»** (ставит из
  встроенного payload, спросит пароль админа). После установки выберите
  стратегию и включите тоггл.
- **Telegram.** Прокси поднимается автоматически; кнопка «Открыть в
  Telegram» доставляет ссылку в запущенный клиент.
- **Автозапуск.** «Запускать при входе в macOS» в настройках добавляет
  приложение в Login Items (launchd).

## Управление окном (macOS)

Нативный заголовок окна отключён (`frame: false`), поэтому вместо
системных «светофоров» рисуются свои, в левом верхнем углу:

- 🔴 **Красная** — **прячет** окно (в Dock/трей), **не завершая** работу
  приложения. Вернуть окно: клик по иконке в Dock или по иконке в трее.
- 🟡 **Жёлтая** — свернуть.
- 🟢 **Зелёная** — развернуть/восстановить.

Полностью выйти из приложения: **⌘Q** или Quit через Dock/трей.

## Отличия от Windows-версии

Сделано специально под macOS, чтобы не ломать Windows-сборку:

- В настройках **нет** переключателя «Тихий старт (без окна)».
- Лейбл автозапуска: **«Запускать при входе в macOS»** (вместо «…в Windows»).
- На странице Zapret **отключена** кнопка «Запустить тест» и авто-тест при
  открытии — стратегии выбираются вручную.
- При ошибке запуска Zapret показывается кнопка **«Попробовать еще раз»**.
- Если Zapret не поднялся и `engine.log` не создан, сообщение гласит
  **«Отключите VPN и попробуйте запустить Zapret ещё раз.»** (вместо сырой
  диагностики).

## Если что-то не работает

### Приложение не открывается («повреждено» / «не может быть открыто»)
macOS Gatekeeper. Снимите карантин: `xattr -cr /Applications/Slipgate.app`,
затем запускайте правым кликом → Открыть. Это не баг, а отсутствие
нотаризации Apple (см. «Известные ограничения»).

### Zapret не устанавливается / установка падает
- Убедитесь, что ввели **пароль администратора** в всплывающем окне
  osascript (оно висит пару секунд — не закрывайте).
- Если предыдущая неудачная попытка оставила файлы в
  `/Library/Application Support/ZapretMac`, повторный клик «Установить
  Zapret» пойдёт по ветке обновления и сам поднимет демон.
- Снесите вручную при необходимости: удалите
  `/Library/Application Support/ZapretMac` и
  `/Library/LaunchDaemons/io.github.flowseal.zapretmac.plist`, затем
  попробуйте снова.

### «utunws не запустился» / «Отключите VPN»
Обычно значит, что активный VPN/сетевой клиент мешает Zapret поднять
сеть. Выключите VPN, нажмите **«Попробовать еще раз»**. Если не помогло и
в `/Library/Application Support/ZapretMac/engine.log` пусто — пришлите мне
содержимое `engine.log` и вывод `log show --predicate 'process == "utunws"'`
(последние ~50 строк), разберёмся.

### Telegram не подключается
Прокси = наша пересборка TgWsProxy (Python/PyInstaller, подписана ad-hoc
без hardened runtime). Проверьте, что процесс `TgWsProxy` запущен (можно
через «Логи» в приложении). Если прокси падает с ошибкой загрузки
Python-библиотеки — это уже чинилось в сборке; при повторе пришлите
вывод из карточки ошибки.

### Красная кнопка «закрывает» программу
Нет — она **прячет** окно, приложение продолжает работать в Dock/трее.
Чтобы выйти полностью — ⌘Q или Quit.

## Что уже исправлено (в этой сборке)

Эти проблемы macOS-версии были найдены и устранены в процессе портирования:

- ✅ **Дублирование кнопок управления окном** — убран конфликт
  `frame:false` + `titleBarStyle:'hidden'`, теперь «светофоры» единственные.
- ✅ **Кнопки были слишком низко** — прибиты к реальному месту
  (top-left), сайдбар сдвинут вниз, чтобы не перекрывать их.
- ✅ **Красная кнопка полностью закрывала приложение** — теперь прячет
  окно (возврат через Dock/трей), не завершая процесс.
- ✅ **TgWsProxy падал с «Failed to load Python shared library … different
  Team IDs» (exit 255)** — бинарник готовится в writable-каталог и
  подписывается ad-hoc без hardened runtime (library validation выключен).
- ✅ **«Zapret не установлен на Mac»** — неверный префикс распаковки payload
  (`bin/utunws` теперь плоско раскладывается).
- ✅ **«utunws did not stay running (1)» при установке** — списки
  DPI-стратегий создаются ДО вызова `install.sh`.
- ✅ **«Скопированный payload не содержит install.sh»** — код устойчив к
  любой раскладке payload (поиск корня + выравнивание).
- ✅ **`engine.log: MISSING` при старте** — `run.sh` переписан: логирует
  каждый шаг pre-flight и делает bounded-retry детекта сети, вместо
  молчаливого выхода.
- ✅ **Нет кнопки установки Zapret на свежей macOS** — добавлена установка
  из встроенного payload.
- ✅ **«Тихий старт» и лейбл «Windows» в настройках Mac** — убраны/заменены.
- ✅ **Нет кнопки повтора при ошибке Zapret** — добавлена
  «Попробовать еще раз».

## Известные ограничения (пока не чиним / чинить дорого)

- ⚠️ **Нет подписи Apple и нотаризации.** Приложение не проходит Gatekeeper
  «из коробки» — нужен `xattr -cr` + Open Anyway. Полноценное решение —
  платный Apple Developer сертификат + `notarytool` в CI. Это не блокирует
  работу, но требует ручного шага при установке.
- ⚠️ **Только Apple Silicon (arm64).** Нет сборки под Intel Mac. Можно
  добавить второй таргет в `electron-builder` (`--mac --x64`), но он пока
  не настроен.
- ⚠️ **Zapret требует пароль администратора** при каждой установке и
  обновлении (системное требование macOS LaunchDaemon). Неустранимо без
  предварительного права на управление системой.
- ⚠️ **Авто-тест стратегий отключён на macOS** — подбор «лучшей»
  стратегии делается вручную. Вернуть можно, но сейчас выключено по дизайну
  (на macOS тест шумит и не нужен в UI).
- ⚠️ **Сообщение «Отключите VPN» — эвристика.** Реальная причина
  `engine.log: MISSING` не всегда VPN (может быть ещё не проснувшаяся сеть
  после сна и т.п.), но для пользователя оставили короткую подсказку.
